# To-Do List App

A clean, responsive To-Do List application built from scratch using **HTML, CSS, and Vanilla JavaScript**. 

## Features
* **Add Tasks:** Quickly add new tasks to your list.
* **Delete Tasks:** Remove tasks you've completed or no longer need.
* **Data Persistence:** Uses `localStorage` and `JSON` to ensure your tasks are saved even if you refresh or close the browser.
* **Responsive Design:** Centered layout that looks great on both desktop and mobile screens.

## Technologies Used
* HTML5
* CSS3 (Flexbox)
* JavaScript (DOM Manipulation, Event Listeners, LocalStorage)
